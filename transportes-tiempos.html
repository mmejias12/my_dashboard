🔒 Credenciales
Esta página no tiene ni puede tener el usuario ni la contraseña del GPS. Todas las consultas van a /api/gps-stops-proxy, que autentica del lado servidor.
La credencial vive en las Application Settings del Static Web App, en GPS_LOGIN y GPS_PASSWORD. No está en este archivo ni en el navegador.
📌 Endpoint activo
GetStopsDataRangeByPlate
Parámetros: sLogin · sPassword · sPlate · sStartDate · sEndDate · iMinStopTime
Formato fecha: YYYY/MM/DD HH:MM:SS · Tiempo mínimo en minutos
🗄 Proxy Azure (recomendado)
Para evitar CORS configura un Azure Function como proxy:
/api/gps-stops-proxy?desde=2026/04/21 00:00:00&hasta=2026/04/21 23:59:59&time=60
